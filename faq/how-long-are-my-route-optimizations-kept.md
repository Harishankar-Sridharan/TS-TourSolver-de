# 3. Wie lange werden meine Routenoptimierungen gespeichert?

Jede in TourSolver durchgeführte Routenoptimierung wird in einer Simulation gespeichert. Simulationen werden dann für eine Dauer aufbewahrt, die je nach Validierungszyklus variiert:

* Eine Simulation, die **gespeichert, aber nicht validiert ist** wird in TourSolver für **zwei Monate**
* Eine Simulation, die **gespeichert und anschließend validiert** wird in TourSolver für **ein Jahr (12 Monate)**

Eine Simulation kann auf zwei Arten validiert werden:

* Von der[ ](https://www.toursolver.com/en/faq/managing-simulations-toursolver)Liste der Simulationen zugänglich über die TourSolver-Startseite
* Von der Fenster mit Optimierungsergebnissen auf der Optimierungsseite
