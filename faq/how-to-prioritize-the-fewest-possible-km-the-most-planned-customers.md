# 6. Wie priorisiere ich die möglichst geringsten km / die meisten geplanten Kunden?

Während der Optimierung können Sie Prioritäten im **Optimierungseinstellungen** unter dem **Optimierungsprioritäten** Tab einstellen. Passen Sie die folgenden Parameter basierend auf Ihren Zielen an:

* **Kilometer reduzieren**: Niedrig / Normal / Wichtig
* **Arbeitszeitfenster verkürzen**: Niedrig / Normal / Wichtig
* **Anzahl der Besuche maximieren**: Niedrig / Normal / Wichtig
* **So wenige Ressourcen wie möglich verwenden**: Niedrig / Normal / Wichtig

Diese Einstellungen beeinflussen, wie der Optimierungsalgorithmus Ihre Einschränkungen ausbalanciert.\
**Tipp:** Weisen Sie jedem Parameter zur Erzielung bester Ergebnisse unterschiedliche Prioritätsstufen zu. Alle Einschränkungen auf „Wichtig“ zu setzen führt normalerweise **nicht** zu optimalen Ergebnissen.
