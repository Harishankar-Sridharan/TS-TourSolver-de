# Bevorstehende Ankunft

## 1. Einführung

Das **Bevorstehende Ankunft** Die Funktion verbessert das Kundenerlebnis, indem sie Echtzeit-Updates zum Lieferstatus bereitstellt. Sie erstellt automatisch einen Link mit geschätzter Ankunftszeit (ETA) und sendet ihn an Ihren Kunden, sobald der Lieferprozess beginnt.

**Der zentrale Nutzen ist Transparenz**: Wenn der Kunde auf diesen Link klickt, kann er **den Live-Standort des Zustellers verfolgen**.

## 3. Funktionsbeschreibungen mit Vorteilen

Die Funktion „Bevorstehende Ankunft" ermöglicht proaktive Kommunikation und stellt sicher, dass Kunden bereit sind, ihre Artikel entgegenzunehmen.

| Funktion                               | Beschreibung                                                                                                                                                      |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ETA-Link**                           | Ein Link mit der geschätzten Ankunftszeit (ETA) wird automatisch erstellt und gesendet, sobald die Lieferung abgeschlossen ist.                                   |
| **Bearbeitung des E-Mail-Betreffs**    | Sie können den **E-Mail-Betreff** eingeben und anpassen, damit Kunden sofort den Zweck der Nachricht erkennen.                                                    |
| **Bearbeitung des Nachrichtenkörpers** | Sie können den **Nachrichtentext bearbeiten** der an Ihre Kunden gesendet wird, und so eine persönliche Sprache und wichtige Details einfügen                     |
| **Personalisierungs-Tags ($)**         | Wenn Sie das **Dollarzeichen** ($) eingeben, werden Optionen angezeigt, die Sie direkt in den E-Mail-Text einfügen und bearbeiten können, was Ihnen Zeit spart.   |
| **Vorschaufenster**                    | Bevor Sie speichern, können Sie die **Vorschau** der genauen Nachricht sehen, die gesendet wird, um sicherzustellen, dass sie professionell und korrekt aussieht. |
| **Live-Standortverfolgung**            | Der Link ermöglicht es dem Kunden, den Live-Standort der Lieferung (oder des Zustellers) zu verfolgen.                                                            |
| **Ausgehende E-Mail**                  | Option zum Aktivieren des Versands des ETA-Links per E-Mail.                                                                                                      |
| **Ausgehende SMS**                     | Option zum Aktivieren des Versands des ETA-Links per SMS.                                                                                                         |

## 5. Produktivitätstipps

Hier sind einige Möglichkeiten, die Wirksamkeit Ihrer Benachrichtigungen zur bevorstehenden Ankunft zu maximieren:

* ($). Dies zeigt Optionen, die Sie zur Bearbeitung des E-Mail-Textes verwenden können. **Dualer Kommunikationskanal:** Erwägen Sie, **beide** ausgehende E-Mails und ausgehende SMS zu aktivieren. Die Verwendung beider Methoden stellt sicher, dass der Kunde die wichtigen ETA-Informationen erhält, unabhängig davon, ob er zuerst seinen Posteingang oder seine Textnachrichten prüft.
* ($). Dies zeigt Optionen, die Sie zur Bearbeitung des E-Mail-Textes verwenden können. **Immer Vorschau verwenden:** Verwenden Sie die Option, um **die Vorschau der E-Mail zu sehen** vor dem Speichern der Konfigurationsänderungen. Dies ist Ihre Gelegenheit zu überprüfen, ob die Nachricht den Link zum Live-Standort wie erwartet enthält.
* ⚠️ **Verständnis der Auslösezeitpunkte:** Denken Sie daran, dass der ETA-Link gesendet wird _sobald der Zusteller die Lieferphase abgeschlossen hat_ (das heißt, er ist auf dem Weg zum Kunden). Stellen Sie sicher, dass Ihre operativen Definitionen von „Lieferung abgeschlossen“ mit dem Zeitpunkt übereinstimmen, zu dem Sie möchten, dass der Kunde beginnt, den Live-Standort zu verfolgen.
